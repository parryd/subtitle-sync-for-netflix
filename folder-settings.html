Subtitle folder

Point this at a folder of .srt/.vtt files. When you land on an episode you've already got a file for in that folder, it loads automatically — no picking a file each time.

Matching is done by filename: season/episode numbers in the file name (like S01E07 or 1x07) are compared against what Netflix shows for the current episode. Files are only ever read from this folder, never downloaded or modified.
